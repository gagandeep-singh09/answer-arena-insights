# Answer Arena Insights

Build a fully functional responsive web application named AI Product Evaluator. Use a dark navy, electric blue and purple professional dashboard design. Create working navigation for Dashboard, Run Evaluation, View Reports, Bug Reports, History and Settings. Build a question input page that sends the exact same user question to OpenAI and Google Gemini through secure server-side API functions, displays both responses side by side, handles loading and errors, and lets the user select a preferred answer. Save questions, both responses, ratings, selected model and timestamps in Supabase. Build reports and dashboard metrics using only real saved evaluation data. Never create fake scores or sample metrics as real results. Store API keys only as server-side secrets, never in frontend code. Add a demo mode with clearly labelled sample data until API keys are configured.
